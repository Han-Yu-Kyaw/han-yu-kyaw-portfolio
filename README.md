# Han Yu Kyaw Portfolio

A static, responsive portfolio with English/Japanese and dark/light theme switches. No build tools are needed.

## Upload to your existing GitHub repository

1. Open `https://github.com/han-yu-kyaw/han-yu-kyaw-portfolio` and select the **main** branch.
2. Choose **Add file → Upload files**.
3. Unzip the download, then drag these files (not the enclosing folder) into the repository: `index.html`, `styles.css`, `script.js`, `favicon.svg`, and `Han-Yu-Kyaw-CV.pdf`.
4. Choose **Commit changes**. The new files replace the existing files with the same names. You may also upload this `README.md`.
5. Open **Settings → Pages** and confirm the publishing source is the **main** branch and **/(root)** folder. Select **Visit site** to open the published page. GitHub Pages updates may take several minutes.

Your existing address should remain `https://han-yu-kyaw.github.io/han-yu-kyaw-portfolio/`.

## Customize

Edit `index.html` to change project descriptions and contact information. The Japanese translations are in the `japanese` object in `script.js`; update the matching English and Japanese entries together. Replace `Han-Yu-Kyaw-CV.pdf` with your current CV while keeping the filename, or change its link in `index.html`.

The internship project description intentionally excludes private records and the dashboard URL. Review the public wording with your supervisor before sharing details of the organization or findings.
